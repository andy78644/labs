這個頁面沒有伺服器，存檔是用你的 GitHub token 直接改 repo 裡的 flight-watch/data/watchlist.json。Token 只會存在這個瀏覽器裡。

怎麼拿 token？（一次就好）
  1. 打開 GitHub → Settings → Fine-grained tokens → Generate new token。
  2. 名稱隨便取（例如 flight-watch），到期日可以選一年。
  3. Repository access 選 Only select repositories，只勾 labs。
  4. Permissions → Repository permissions：Contents 設 Read and write；想用「立即掃描」按鈕的話，Actions 也設 Read and write。
  5. 按 Generate，複製 github_pat_ 開頭的那串，貼到上面。
這個 token 只能改 labs 這個 repo。手機上也可以照做，每台裝置貼一次就好。不要在公用電腦勾「記住」。
