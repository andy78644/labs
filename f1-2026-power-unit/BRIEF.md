# Inside the 2026 F1 Power Unit — 互動教學 lab brief

## 目的
做一個互動教學網頁，讓一般人看懂 **2026 年 F1 新規則下的動力單元**：它怎麼運作、跟以前有什麼不同、能量怎麼流動。

## 風格（原創的「轉播畫面／維修站牆」風格）
- 底色接近純黑（`#0a0a0c`），用程式碼畫的 2×2 斜紋碳纖維紋理（不用圖片檔）
- 介面以紅（`#e3102a`）、白、黑為主；即時遙測用螢光黃綠（`#d4ff33`）；區段計時用紫／綠／黃（只用在一圈模擬的 S1–S3，紫＝本節最佳、綠＝比上一圈快、黃＝比上一圈慢）
- 能量顏色只留給資料，在深色底上要清楚：電力部署＝青綠、回收＝藍、燃料＝橘、廢氣＝紅粉、進氣＝淡藍灰、曲軸＝金、MGU-H＝紫
- 面板是斜切角和平行四邊形（clip-path、skew），不用毛玻璃；紅白路緣石條紋點綴標題列和遙測列；標題列有少量速度線動態
- 字型：Saira（用 wdth 軸做粗體斜體窄字標題）＋ JetBrains Mono（數值）
- 版面像轉播畫面：上方標題列＋章節分頁、左側維修站控制台、右側教學面板（沒選章節時顯示計時塔式的課程列表）、底部 lower-third 遙測條（換檔燈、區段計時、賽道圖）；電影模式有 letterbox 和 lower-third 字幕條
- 3D 品質：暗色攝影棚打光（柔和主光、冷白與紅色輪廓光）、程式碼生成的攝影棚環境反射、陰影、GTAO、bloom 只給高溫部件、tone mapping。**用自己寫的 shader 做重點視覺化**
- 不用 F1 官方商標、字型、真實車隊名稱、塗裝或贊助商
- 互動：拖曳旋轉、捲動縮放、數字鍵切換、爆炸圖切換、電影運鏡模式、`/` 隱藏介面、按鍵說明
- 手機也要能用

## 技術限制
- Three.js（最新穩定版），用 import map 從 jsDelivr 載入。**不要 build step**，最後產出**單一 `index.html`**（可以內嵌 JS/CSS）
- **零素材檔**：所有模型用程式碼生成（程序化幾何），聲音用 Web Audio 合成
- 用 `python3 -m http.server` 就能跑

## 內容：2026 動力單元
**開工前先上網查 FIA 2026 動力單元規則的官方或可信來源，確認以下數字**，並在 README 附上來源。查不到確定值就標「約」。
- 1.6L V6 渦輪，90° 夾角，轉速上限 15,000 rpm
- **拿掉 MGU-H**（2014–2025 年有）；保留 MGU-K，功率大幅提升到約 350 kW（以前約 120 kW）
- 內燃機功率降到約 400 kW，電力約佔一半
- 燃料流量改用能量限制（MJ/h），使用 100% 永續燃料
- 每圈能回收的能量上限提高
- 超車輔助：新的手動 override 模式（取代 DRS 的角色，給追車者額外電力）。主動空力雖然屬於車體，但可以在「模式」段落簡單帶到

## 場景與互動
1. **主模型**：風格化但有機械感的 V6 動力單元，包含兩排各 3 缸（90°）、曲軸、連桿、活塞、凸輪軸、渦輪增壓器（壓縮端和渦輪端）、MGU-K（接到曲軸或齒輪箱）、電池（ES）、控制電子（CE）、排氣管
2. **轉速滑桿**（例如 4,000–15,000 rpm）：活塞、曲軸、凸輪、渦輪同步運轉，點火順序正確，**引擎聲依轉速即時合成**（V6 的點火頻率 = rpm/60 × 3，加上諧波、渦輪嘯聲）。可以設靜音開關，預設靜音或等使用者第一次互動後才出聲
3. **剖面／透視模式**：看得到汽缸內部的四行程循環（進氣、壓縮、點火、排氣），燃燒時發光
4. **爆炸圖**：一鍵把零件分開，每個零件有標籤
5. **能量流視覺化**：用發光粒子表示燃料 → 曲軸、剎車回收 → MGU-K → 電池、電池 → MGU-K → 驅動。讀數即時顯示 ICE kW、MGU-K kW、電池 SoC、這圈已回收／部署的 MJ
6. **駕駛模式**：排位賽（全力部署）／正賽／省電充電（lift-and-coast）／超車 override，切換後能量流向和數值要跟著變
7. **2025 vs 2026 比較**：切換後 MGU-H 出現或消失，功率比例圖跟著變
8. **一圈模擬**（加分項）：簡化的賽道速度曲線，看直道部署、彎道回收的節奏

## 教學卡片（側邊，編號，每段對應場景）
1. 什麼是動力單元（不只是引擎）
2. 四行程和 V6 的點火順序
3. 渦輪：為什麼要增壓、渦輪遲滯
4. 2026 最大的改變：MGU-H 沒了、電力變一半
5. MGU-K 和電池：回收和部署
6. 燃料和能量限制
7. 模式和超車 override

文案要用淺白的英文（可以另外加繁體中文切換，加分項）。每段都要能讓人在畫面上找到對應的東西（例如點卡片時鏡頭飛過去並高亮該零件）。
